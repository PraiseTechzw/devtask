# Code of Conduct

DevTask is committed to a welcoming, respectful, and inclusive community. Contributors must communicate professionally and must not engage in harassment, discrimination, intimidation, personal attacks, unwanted sexual attention, or disclosure of private information.

Maintainers may remove comments, close issues, or limit participation when behavior conflicts with this standard. Concerns should be reported privately through the contact channel associated with the repository rather than in a public issue.

This code of conduct applies in repository issues, pull requests, discussions, reviews, and other project spaces.
