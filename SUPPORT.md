# Support

Use GitHub Issues for reproducible bugs and scoped feature requests. Use the issue forms so maintainers receive the platform, reproduction details, and expected behavior needed to investigate.

Before opening an issue, search existing issues and review the [README](README.md), [`docs/BACKEND_SETUP.md`](docs/BACKEND_SETUP.md), and [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Configuration questions should include the command that was run and the relevant error message, with credentials and tokens removed.

Do not post secrets, private user data, Clerk tokens, GitHub tokens, OAuth codes, or full environment files in public issues. Security vulnerabilities belong in a private report as described in [`SECURITY.md`](SECURITY.md).
